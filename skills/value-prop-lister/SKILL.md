# Value Prop Lister

The value props that win deals are the ones customers say back to you, not the ones on the homepage. This skill mines real evidence and ranks what actually matters.

## Input needed
- Won-deal notes, call transcripts, testimonials, reviews, or anywhere a customer described the value in their own words.

If the user has none, say so plainly and suggest they pull 3-5 recent customer quotes first. Do not invent value props from thin air; a guessed benefit poisons every email built on it.

## Method
1. Read every piece of evidence and pull the exact phrases where a customer describes a benefit, an outcome, or a relief.
2. Cluster the phrases into distinct value props. Merge duplicates.
3. Rank by three things: how often it shows up, how strongly it's said, and how tightly it's tied to money or time.
4. Keep the single strongest real quote as proof for each.

## Output
Write into **section 5 (Value propositions)** of `outreach-brief.md` as a ranked list. For each:
- The value prop in plain language.
- The evidence: one verbatim customer quote.
- A line on why it ranks where it does.

Lead with the value prop that has the most and strongest evidence. That is your cold-email opener fuel.
