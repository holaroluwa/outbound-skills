# Cold Call Script

A good cold call earns the next 30 seconds, then the next. This script is built in beats you can actually say out loud, with room to listen.

## Input needed
- Target title and company type.
- Persona, top pains, value props, and competitor handling from `outreach-brief.md` if present.

## Method
Write the script in these beats:
1. **Opening**, an honest pattern-interrupt. Name who you are and that it's a cold call, like a human.
2. **Permission**, ask for 30 seconds. Earning permission beats steamrolling.
3. **Pain question**, a sharp question tied to pain #1 that gets them talking, in their language.
4. **Value bridge**, one or two lines connecting their answer to your offer. Short.
5. **CTA**, a small next step (a 15-minute look, not a signature).
6. **Three objection handlers**, for the likely pushbacks ("we already use X", "no budget", "send me an email"). Calm, short, re-open the conversation.

## Voice rules
- Conversational and spoken, not written-and-read. Contractions, short lines.
- No scripted-robot phrases. Leave explicit "[pause / listen]" cues so it stays a conversation.

## Output
The full script in labelled beats, plus the three objection handlers, each with the likely objection and the response underneath.
